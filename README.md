# Game Haven Hub

Создать игровой портал HTML5 игр в стиле CrazyGames по спецификации из репозитория https://github.com/artsmart9999-cpu/game-haven-io:

- Тёмная тема (#0f172a / slate dark) с акцентными градиентами.
- Сворачиваемый боковой сайдбар с категориями игр: Гонки, Экшен, Стрелялки, Головоломки, Спорт, .io, Приключения, Казуальные с иконками и счётчиками.
- Верхняя панель поиска с живой фильтрацией по названию и тегам, переключателем сортировки (популярные, новые, рейтинг).
- Главный баннер (Hero) и карусель рекомендуемых/трендовых игр.
- Адаптивная сетка карточек игр с ховер-эффектами, бейджами, количеством сыгранных раз и кнопкой избранного.
- Страница и модальное окно запуска игры: контейнер 16:9 для HTML5 iframe (совместимый с GameDistribution), полноэкранный режим, кнопки лайк/дизлайк, блок управления (WASD / мышь / клавиатура), описание, теги и блок похожих игр.
- Локальное сохранение недавних игр (История) и избранного (Мои игры) в браузере.
- Плейсхолдеры для рекламных баннеров (728x90 сверху, 300x250 в боковой панели).
- Начальный каталог готовых браузерных игр с описаниями, категориями и управлением.
